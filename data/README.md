# 本地训练数据

此目录不包含训练数据或固定评估切分。若你已从上游获得并获准使用兼容数据，可将 JSONL 文件放在这里，或通过 `RAN_MONITOR_DATA_PATH` 指定其绝对路径。

训练文件每行应为一个窗口，包含有效的 `start_time`、`end_time`、16 项数值 KPI（每项 128 个点）和 `anomalies` 标签。训练集还须覆盖正常、拥塞、设备故障、无线干扰和移动性五种类别。仓库根目录的 `sample_window.json` 是合成推理样例，不满足训练集规模与类别要求。

TelecomTS 来源、上游许可元数据和本仓库不再分发该数据的原因见 [数据来源说明](../DATA_SOURCES.md)。
